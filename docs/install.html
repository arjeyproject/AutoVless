پیش‌نیازها را جمع کن

قبل از تایپ اولین دستور، این چهار چیز باید آماده باشد.

  • یک سرور لینوکس با اوبونتو ۲۲.۰۴ یا ۲۴.۰۴، حداقل ۱ هسته و ۱ گیگ رم.
  • دسترسی ریشه یا کاربری با sudo.
  • توکن ربات از BotFather.
  • آیدی عددی خودت برای پنل مدیریت.
اکانت کلادفلرخودت به اکانت کلادفلر نیازی نداری. هر کاربر توکن اکانت شخصی‌اش را می‌فرستد و ورکر روی اکانت خودش ساخته می‌شود.
۱

ربات را در تلگرام بساز

توکن کلید همه‌چیز است؛ جایی امن نگه‌اش دار.

  1. @BotFather را باز کن و /newbot بفرست.
  2. یک نام نمایشی بده، مثل AutoVless.
  3. یک یوزرنیم بده که به bot ختم شود.
  4. توکن را کپی کن. شکلش شبیه 8123456789:AAF-Example... است.
۲

آیدی عددی ادمین را بگیر

بدون این عدد، پنل مدیریت برای هیچ‌کس باز نمی‌شود.

به @userinfobot پیام بده. عدد فیلد Id آیدی توست.

چند ادمینآیدی‌ها را با کاما جدا کن: 111111111,222222222
۳

به سرور وصل شو

ساعت غلط سرور باعث خطای TLS در اسکنر می‌شود؛ این بخش را رد نکن.

آماده‌سازی

ssh root@SERVER_IP
apt update && apt upgrade -y
apt install -y curl git ca-certificates
timedatectl set-timezone Asia/Tehran
رم یک گیگاگر سواپ نداری یک گیگ بساز: fallocate -l 1G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile
۴

نصب یک‌خطی

داکر را نصب می‌کند، پروژه را می‌گیرد، env می‌سازد و ربات را بالا می‌آورد.

با دسترسی ریشه

bash <(curl -fsSL https://raw.githubusercontent.com/arjeyproject/AutoVless/main/install.sh)

دو سوال می‌پرسد: توکن ربات و آیدی عددی ادمین.

تست سریعدر تلگرام به ربات خودت /start بفرست. باید منوی شیشه‌ای را ببینی.
۵

نصب دستی

همان کار، ولی هر مرحله زیر دست خودت.

چهار گام

curl -fsSL https://get.docker.com | sh
systemctl enable --now docker

git clone https://github.com/arjeyproject/AutoVless.git /opt/autovless
cd /opt/autovless

cp .env.example .env
nano .env        # BOT_TOKEN and ADMIN_IDS
chmod 600 .env

mkdir -p data
docker compose up -d --build
docker compose logs -f

برای خروج از لاگ Ctrl + C بزن؛ ربات در پس‌زمینه روشن می‌ماند.

۶

راهنمای فایل env

فقط دو مقدار اول اجباری‌اند. بقیه برای سرور یک هسته تنطیم شده‌اند.

کلیدپیش‌فرضتوضیح
BOT_TOKEN—توکن BotFather. اجباری.
ADMIN_IDS—آیدی عددی ادمین‌ها با کاما. اجباری.
BRANDAutoVlessنامی که در اسم کانفیگ‌ها می‌آید.
DEFAULT_LANGfaزبان پیش‌فرض؛ fa یا en.
TLS_CONFIG_COUNT3تعداد کانفیگ روی پورت‌های TLS.
HTTP_CONFIG_COUNT3تعداد کانفیگ روی پورت ۸۰.
TLS_PORTS443مجاز: 443, 2053, 2083, 2087, 2096, 8443
HTTP_PORTS80مجاز: 80, 8080, 8880, 2052, 2082, 2086, 2095
SCAN_INTERVAL600فاصله هر دور اسکن، به ثانیه.
SCAN_BATCH1200تعداد آدرس در هر دور، برای هر پورت.
SCAN_CONCURRENCY160سوکت هم‌زمان. روی یک هسته بیش از ۲۰۰ نبر.
POOL_SIZE120تعداد اندپوینت در استخر.
PROXY_IPخالیرله اختیاری برای مقصدهای دور از دسترس کلادفلر.
STORE_TOKENStrueنگه‌داری رمزنگاری‌شده توکن برای بازسازی و حذف.
SECRET_KEYخالیخالی بگذار؛ در data/.secret ساخته می‌شود.
بعد از هر تغییرسرویس را ری‌استارت کن: docker compose restart
۷

اولین اجرا و پنل مدیریت

اسکنر همان لحطه بوت شروع می‌کند؛ یک دقیقه به او وقت بده.

  1. /start بفرست. دکمه پنل مدیریت فقط برای آیدی‌های ADMIN_IDS دیده می‌شود.
  2. در موتور اسکن، اگر استخر صفر است اسکن فوری را بزن.
  3. در قفل کانال کانال‌های اجباری را اضافه کن. ربات باید از قبل ادمین باشد.
  4. در تنطیمات حالت سرویس، اجازه ساخت پنل و عضویت اجباری را خاموش و روشن کن.
  5. پشتیبان‌گیری فایل دیتابیس را برایت می‌فرستد.
۸

مسیر کاربر، از توکن تا کانفیگ

یک بار خودت کامل تستش کن.

  1. کاربر ساخت پنل توربو را می‌زند: دو دکمه ثبت نام و دریافت توکن.
  2. دکمه دریافت توکن، صفحه کلادفلر را با دسترسی‌های آماده باز می‌کند.
  3. Continue to summary و بعد Create Token.
  4. توکن را در چت ربات پیست می‌کند. ربات پیام توکن را فوراً پاک می‌کند.
  5. ربات توکن را اعتبارسنجی می‌کند، دامنه workers.dev را آماده می‌کند، ورکر را آپلود و سلامتش را تست می‌کند.
  6. شش کانفیگ به همراه لینک اشتراک، بارکد QR و خروجی Clash و sing-box تحویل داده می‌شود.

چرا این کانفیگ‌ها کار می‌کنند

آدرس اتصال یک آی‌پی تمیز کلادفلر است، ولی Host و sni روی دامنه ورکر کاربر تنطیم شده‌اند. به همین دلیل عوض کردن آی‌پی هیچ‌وقت کانفیگ را نمی‌شکند؛ فقط درِ ورود تغییر می‌کند.

شکل نهایی کانفیگ پورت ۴۴۳

vless://UUID@104.16.1.55:443?encryption=none&security=tls
&type=ws&host=auto-565414.avl-9f2c.workers.dev
&sni=auto-565414.avl-9f2c.workers.dev&fp=chrome
&path=%2F%3Fed%3D2560#@AutoVless | VLESS | 18ms | CDG | #2
کانفیگ‌های پورت ۸۰همان ساختار، ولی security=none و بدون sni.
۹

نگهداری روزمره

پنج دستوری که واقعاً لازمت می‌شود.

از داخل /opt/autovless

docker compose logs -f          # live logs
docker compose restart         # restart
docker compose down            # stop
git pull && docker compose up -d --build   # update
cp data/autovless.db ~/backup.db          # backup

مصرف منابع را با docker stats autovless ببین. در حالت عادی نباید از ۳۰۰ مگابایت رم عبور کند.

۱۰

رفع اشکال

هر مشکلی که واقعاً پیش می‌آید، با علت و راه‌حل.

ربات به /start جواب نمی‌دهد

docker compose logs --tail=50 را بگیر. پیام BOT_TOKEN is missing یعنی فایل env پر نشده؛ Unauthorized یعنی توکن غلط است.

پیام «کلادفلر این توکن را قبول نکرد»

توکن ناقص کپی شده، کاربر Create Token را نزده، یا دسترسی‌ها را دستی عوض کرده. دوباره از همان دکمه ربات شروع کند.

کانفیگ ساخته شد ولی وصل نمی‌شود

اول در کلاینت Real Delay بگیر. اگر همه تایم‌اوت دادند:

  • Fragment را روشن کن.
  • کانفیگ‌های پورت ۸۰ را امتحان کن.
  • در ربات اسکن مجدد و بعد بازسازی پنل را بزن.

اگر https://HOST/healthz در مرورگر باز شد ولی کانفیگ کار نکرد، مشکل آی‌پی ورودی است نه ورکر.

آدرس ورکر خطای 404 یا 522 می‌دهد

کلادفلر برای انتشار یک دامنه workers.dev تازه تا یک دقیقه وقت می‌خواهد. صبر کن و بازسازی پنل را بزن. اگر ادامه داشت، کاربر یک بار بخش Workers را در داشبورد باز کند.

استخر آی‌پی تمیز خالی می‌ماند

خروجی سرور به رنج‌های کلادفلر بسته است. تست: curl -sI https://104.16.1.1 --resolve cloudflare.com:443:104.16.1.1. اگر جواب داد ولی استخر خالی ماند، SCAN_TIMEOUT_MS را به 2500 ببر.

قفل کانال کار نمی‌کند

ربات باید در کانال ادمین باشد، وگرنه عضویت را نمی‌خواند و آن کانال را نادیده می‌گیرد. کانال را حذف کن، ربات را ادمین کن، دوباره اضافه کن.

کانتینر مدام ری‌استارت می‌شود یا رم پر می‌شود

سواپ بساز و این مقادیر را کم کن:

SCAN_CONCURRENCY=90
SCAN_BATCH=600
SCAN_INTERVAL=900

بعد docker compose restart.

می‌خواهم پورت‌های بیشتری بدهم
TLS_PORTS=443,8443,2053
HTTP_PORTS=80,8080
TLS_CONFIG_COUNT=4
HTTP_CONFIG_COUNT=4

هر پورت اضافه یک دور اسکن بیشتر است. روی یک هسته از چهار پورت جلوتر نرو.

سرور را عوض کردم، چطور مهاجرت کنم

پوشه data و فایل .env را کامل کپی کن، بعد docker compose up -d --build. کلید رمزنگاری در data/.secret است؛ بدون آن توکن‌های ذخیره‌شده باز نمی‌شوند.
